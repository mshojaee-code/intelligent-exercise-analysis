# Classical baseline evaluation plan

1. Verify the audited CSV hash and run the audit utility. Freeze the five-column order, raw-angle mode and literal label mapping from the schema and audit. Exclude Side, the ground columns, row index and target from predictors.
2. For this CSV, use a seeded stratified 70/15/15 train/validation/test row split (seed 42). Save row indices and hash the split manifest against the CSV hash. Reuse identical partitions and label ordering across models. Call this a within-dataset frame evaluation. Correlated frames and shared people or cameras can inflate every metric. A chronological split by file index also lacks defensible video boundaries.
3. For newly acquired clips, split subjects first, otherwise sessions or entire videos, before extracting frames or windows. Verify disjoint groups and five-class coverage. If groups are insufficient, collect additional examples. Reserve independent labeled recordings for the demonstration evaluation.
4. Fit one Random Forest (100 trees, seed 42), one RBF SVM (C=1, gamma=scale) and one Euclidean 5-neighbor KNN. Use training-only standardization in SVM/KNN pipelines. Use the same training data and avoid a tuning grid. Select by validation macro-F1, breaking ties by measured CPU inference latency. Calibrate any confidence score with training-only folds and choose abstention thresholds on validation. Assess temporal voting separately on ordered clips.
5. Freeze the chosen pipeline before scoring the held-out test set. Record validation accuracy, macro-F1, per-class precision/recall/F1/support and confusion matrices with explicit label order for each comparator. Evaluate the selected model once on the held-out test partition. Report Unknown rate and coverage separately when abstention is enabled. Keep frame evaluation distinct from independent clip results.
6. Record parameters, seeds, code commit, Python/library versions, schema ID, units, label map, split and dataset hashes, score interpretation, and model hash. Keep trained artifacts local and reproduce them from the manifest. Training and metrics belong to the baseline milestone.
